STRUCTURE AND LIBRARIES IN C

Published 2026-11-06 · 8 min read

PROGRAM STRUCTURE

Header Files and Source Files

A header file (.h) acts as an interface. It usually contains declarations such as function prototypes, structure definitions, and macros. A source file (.c) contains implementations: the function bodies and program logic.

Separating declarations from definitions makes code easier to organize and reuse. Other source files can include a header to learn how to call a function without needing its implementation. When an implementation changes, a build system can recompile the affected source file and relink the program.

What Does #include Do?

The C preprocessor handles #include before compilation. It processes the named file as part of the current translation unit.

  • #include <file.h> conventionally searches the compiler's configured system include paths, which are used for standard or installed headers.
  • #include "file.h" conventionally searches the source file's local directory first, then the configured include paths. This form is commonly used for project headers.

Include Guards

Include guards prevent a header from being processed more than once in a translation unit. Without them, the same declarations may be encountered repeatedly and cause redefinition errors. A traditional guard looks like this:

#ifndef MATH_TOOLS_H
#define MATH_TOOLS_H

int add_numbers(int a, int b);

#endif

#pragma once is another widely supported option, though it is not part of the C standard.

STANDARD C LIBRARIES

<string.h>: Working with Strings

C strings are character arrays terminated by a null character, '\0'. Functions in <string.h> work with this convention.

strlen

strlen counts the characters before a string's terminating null character. It does not include that terminator.

Signature: size_t strlen(const char *str); A common use is checking whether a password meets a minimum length.

#include <stdio.h>
#include <string.h>

int main(void) {
    char password[] = "secret123";

    printf("Length: %zu\n", strlen(password));
    return 0;
}

Output: Length: 9

strcpy

strcpy copies a source string, including its terminating null character. The destination must have enough space for the entire string and terminator.

Signature: char *strcpy(char *dest, const char *src); For example, it can copy a known, short default name into a user profile buffer when the buffer is large enough.

#include <stdio.h>
#include <string.h>

int main(void) {
    char username[20];

    strcpy(username, "Admin");
    printf("User is: %s\n", username);
    return 0;
}

Output: User is: Admin

Do not use strcpy unless the destination capacity is known to be sufficient. For input that may be too long, validate the length or use an approach that explicitly limits and checks the copied data.

strcmp

strcmp compares two strings lexicographically. It returns zero when they are equal, a negative value when the first differing character in the first string is lower, or a positive value when it is higher.

Signature: int strcmp(const char *str1, const char *str2); It can be used to compare a command against a reserved word such as EXIT.

#include <stdio.h>
#include <string.h>

int main(void) {
    int result = strcmp("apple", "apple");

    printf("Comparison result: %d\n", result);
    return 0;
}

Output: Comparison result: 0

<ctype.h>: Working with Characters

Character classification and conversion functions accept an int value representing either EOF or a value representable as unsigned char. When passing a possibly signed char, convert it to unsigned char first.

tolower and toupper

tolower converts an uppercase letter to lowercase, and toupper converts a lowercase letter to uppercase. Other characters are returned unchanged.

Signatures: int tolower(int c); and int toupper(int c); They can help normalize user input before checking a yes-or-no response.

#include <ctype.h>
#include <stdio.h>

int main(void) {
    char c = 'A';

    printf("Lower: %c\n", tolower((unsigned char)c));
    return 0;
}

Output: Lower: a

isdigit, isalpha, and isalnum

These functions test whether a character is a decimal digit, alphabetic letter, or alphanumeric character. They return zero when the character does not match and a nonzero value when it does.

Signatures: int isdigit(int c);, int isalpha(int c);, and int isalnum(int c);. For example, isdigit can validate that an input character is a digit.

#include <ctype.h>
#include <stdio.h>

int main(void) {
    char test = '7';

    if (isdigit((unsigned char)test)) {
        printf("It is a digit!\n");
    }
    return 0;
}

Output: It is a digit!

islower and isupper

islower checks whether a character is a lowercase letter; isupper checks for an uppercase letter.

Signatures: int islower(int c); and int isupper(int c); These checks can help enforce a password rule that requires both letter cases.

#include <ctype.h>
#include <stdio.h>

int main(void) {
    char test = 'g';

    if (islower((unsigned char)test)) {
        printf("Lower case detected.\n");
    }
    return 0;
}

Output: Lower case detected.

<stdbool.h>: Booleans in C

In C99 through C17, including <stdbool.h> provides the names bool, true, and false. These are macros for the language's _Bool type and the values 1 and 0. C23 makes these names part of the language, so the header is no longer needed for them in that standard.

Use a boolean to make a condition such as whether a user is signed in or a task is complete clearer than using an unexplained integer.

#include <stdbool.h>
#include <stdio.h>

int main(void) {
    bool is_ready = true;

    printf("Ready: %s\n", is_ready ? "yes" : "no");
    return 0;
}

Before C99, programmers commonly represented false with zero and true with a nonzero integer, sometimes defining their own TRUE and FALSE macros.

memcpy: Copying Raw Memory

memcpy copies a specified number of bytes from one memory region to another. Unlike strcpy, it does not look for a null terminator, so the caller must provide the correct byte count. The source and destination regions must not overlap; use memmove when they might.

Signature: void *memcpy(void *dest, const void *src, size_t n); It can copy a fixed-size array of structures, such as a set of player coordinates for a checkpoint.

#include <stdio.h>
#include <string.h>

int main(void) {
    int src_array[3] = {10, 20, 30};
    int dest_array[3];

    memcpy(dest_array, src_array, sizeof src_array);
    printf("First element: %d\n", dest_array[0]);
    return 0;
}

Output: First element: 10

<stdlib.h>: Dynamic Memory Management

Dynamic allocation is useful when the amount of storage needed is determined while a program runs. Include <stdlib.h> for these functions, check allocation results, and release owned memory with free.

malloc

malloc requests a block of memory of the specified size. The returned memory is uninitialized, and the function returns a null pointer if allocation fails.

Signature: void *malloc(size_t size); One use is allocating an image buffer when its required size is only known at runtime.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *arr = malloc(2 * sizeof *arr);
    if (arr == NULL) {
        return 1;
    }

    arr[0] = 42;
    printf("Allocated: %d\n", arr[0]);
    free(arr);
    return 0;
}

calloc

calloc allocates space for an array of elements and initializes all its bytes to zero. Always check the returned pointer before using it.

Signature: void *calloc(size_t num, size_t size); It is useful when an array should start with every byte set to zero, such as a table of counters.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *arr = calloc(2, sizeof *arr);
    if (arr == NULL) {
        return 1;
    }

    printf("Initialized to: %d\n", arr[1]);
    free(arr);
    return 0;
}

Output: Initialized to: 0

realloc

realloc changes the size of an allocated block. It may keep the block in place or move its contents to a new block. If it fails, it returns NULL and leaves the original allocation intact. Store the result in a temporary pointer so a failure does not lose the original address.

Signature: void *realloc(void *ptr, size_t new_size); It can grow a dynamic array when more entries need to be stored.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *arr = malloc(sizeof *arr);
    if (arr == NULL) {
        return 1;
    }
    arr[0] = 55;

    int *resized = realloc(arr, 2 * sizeof *arr);
    if (resized == NULL) {
        free(arr);
        return 1;
    }
    arr = resized;
    arr[1] = 99;

    printf("Resized: %d, %d\n", arr[0], arr[1]);
    free(arr);
    return 0;
}

Output: Resized: 55, 99

free, Memory Leaks, and Allocation Failures

free releases a block previously returned by a compatible allocation function. A memory leak occurs when a program no longer has a way to reach an allocation but never releases it. Repeated leaks can waste memory over time. Dereferencing a null pointer after a failed allocation is invalid and commonly causes a crash, so check allocation results before use.

Signature: void free(void *ptr); Free each allocation when the program is finished using it, and do not use the pointer afterward.

USER-DEFINED LIBRARIES

A small reusable library can be split into a header with declarations and a source file with implementations.

1. Header: math_tools.h

#ifndef MATH_TOOLS_H
#define MATH_TOOLS_H

int add_numbers(int a, int b);

#endif

2. Implementation: math_tools.c

#include "math_tools.h"

int add_numbers(int a, int b) {
    return a + b;
}

3. Use the Library: main.c

Include the project header with quotes. Compile and link both source files:

gcc main.c math_tools.c -o program
#include <stdio.h>
#include "math_tools.h"

int main(void) {
    printf("Sum: %d\n", add_numbers(5, 10));
    return 0;
}

Output: Sum: 15

Standard and User-Defined Libraries

Standard library headers, such as <string.h>, are supplied with a C implementation and are included with angle brackets. User-defined headers belong to a project and are commonly included with quotes. The project source files that provide the implementation must also be compiled and linked into the program.
