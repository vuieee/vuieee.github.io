ENABLING VARIABLE REFRESH RATE (VRR) ON XORG

Variable Refresh Rate (VRR)—commonly known by its marketing names FreeSync (AMD) or G-Sync (NVIDIA)—is an absolute game-changer. By syncing your monitor's refresh rate to your GPU's framerate, it eliminates screen tearing without the massive input lag penalty of traditional V-Sync.

However, if you are running an Xorg session (X11) on Linux, enabling VRR isn't always a one-click affair. Wayland handles this natively much better these days, but many of us still rely on X11 for specific workflow compatibilities or older games.

Here is the definitive guide to getting VRR working on Xorg.

StepInstructionsCommand / Code
1 Check your hardware. Make sure your monitor supports FreeSync/G-Sync and is connected via DisplayPort. N/A
2 The AMD configuration. If using an AMD GPU with the open-source amdgpu driver, edit the Xorg config. 
sudo nano /etc/X11/xorg.conf.d/20-amdgpu.conf

Add this block:

Section "Device"
    Identifier "AMD"
    Driver "amdgpu"
    Option "TearFree" "true"
    Option "VariableRefresh" "true"
EndSection
3 The NVIDIA configuration. Generate a basic config and use the NVIDIA control panel or edit the config directly. 
sudo nvidia-xconfig

In /etc/X11/xorg.conf, under the "Screen" section:

Option "AllowVRR" "1"
4 Verification. After reboot, verify it's working for AMD. Look for vrr_capable: 1. 
xrandr --props | grep vrr

On Xorg, VRR only works when a single window is fullscreen and uncomposited. Make sure your compositor (like picom or xcompmgr) is set to unredirect fullscreen windows!
